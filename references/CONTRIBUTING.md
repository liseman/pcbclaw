# Contributing

Keep SKILL.md below 10,000 characters; put branch details in references and deterministic functions in scripts. Preserve explicit task overrides, backups, private-data boundaries and truthful release status. Do not hardcode stock, prices, service limits, unverified rotation corrections or model names.

Run python3 -B scripts/test_helpers.py and native skill validation before proposing a change. Include targeted regression cases for helper changes. Test with synthetic fixtures, no real orders/uploads. State whether model behavior was actually exercised or merely inspected. Keep credentials, personal files, generated CAD, caches and third-party datasheets out of the skill distribution.

For repository copies, use ordinary reviewed source changes. For Workshop-managed copies, use the installed Skill Workshop API rather than editing its managed directory. Do not publish unsolicited changes to another user's skill.
